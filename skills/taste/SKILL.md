# taste — routing hub

The design sub-skills live elsewhere on disk and are intentionally not advertised to the
model individually (that costs ~1.7k tokens per request), so:

1. Match the request to one row below.
2. `read` the sub-skill's `SKILL.md` in full.
3. Follow that file as the authoritative instructions — do not work from memory.

Base directory: `~/.pi/agent/git/github.com/Leonxlnx/taste-skill/skills`
